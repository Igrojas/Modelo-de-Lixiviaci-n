# Modelo Fenomenológico de Lixiviación

Este proyecto contiene scripts para el análisis de modelos fenomenológicos de lixiviación.

## Estructura del Proyecto

```
src/
└── scripts/
    ├── main.py
    ├── main_caudal_concentracion.py
    ├── main_caudal_generacion.py
    └── main_caudal_v2.py
```

## Scripts Disponibles

- `main.py` - Script principal
- `main_caudal_concentracion.py` - Análisis de caudal y concentración
- `main_caudal_generacion.py` - Análisis de caudal y generación
- `main_caudal_v2.py` - Versión mejorada del análisis de caudal

## Requisitos

- Python 3.10+
- Dependencias específicas (ver archivos de código)

## Uso

Ejecutar los scripts individuales según sea necesario:

```bash
python src/scripts/main.py
python src/scripts/main_caudal_concentracion.py
python src/scripts/main_caudal_generacion.py
python src/scripts/main_caudal_v2.py
```
